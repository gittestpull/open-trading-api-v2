📖 트레이딩 시스템 가이드

1. 시스템 아키텍처

본 시스템은 대시보드에서 설정한 전략에 따라 독립적인 봇 프로세스가 실시간으로 시장을 감시합니다. 데이터는 한국투자증권(KIS) API와 네이버 금융을 상호 보강하여 수집합니다.

2. 봇 시작 시 동작

봇 카드에서 '시작' 버튼을 누르면 아래 프로세스가 실행됩니다:

  • 실행 스크립트: monitor_scalp_universal.py
  • 감시 주기: 약 10초마다 실시간 시세 조회
  • 데이터 소스: KIS WebSocket + 네이버 금융 보강

3. 매매 로직 상세

A. 진입 (Entry) - 매수 조건

  • RSI 과매도: RSI ≤ 30일 때 자동 매수 신호 발생.
  • 볼린저 밴드 반등: 주가가 볼린저 밴드 하단을 깨고 반등할 때 매수.
  • 수동 지정가: 사용자가 설정한 4개 가격 중 하나라도 터치 시 즉시 매수 (지표 무시).
  • 모멘텀 모드: RSI/볼린저 무시하고 거래량 돌파 시 추격 매수.

B. 청산 (Exit) - 매도 조건

  • 익절: 평단가 대비 설정된 목표 수익률 도달 시 전량 매도.

C. 추가 매수 (Pyramiding) - 물타기

  • 조건: 평단가 대비 설정된 하락폭 (기본 1%) 도달 시.
  • 가중치: 1:2:4:8 비율로 추가 매수하여 평단가를 효과적으로 낮춤.
  • 최대 4회 추가 매수 가능.
⚠️ 주의사항: NXT(야간) 시장은 시장가 주문을 지원하지 않으므로, 시스템이 현재가 기반의 지정가 주문으로 보정하여 체결을 시도합니다.

4. 환경 정책 안내

  • 개발(Dev) (포트 8081): 실시간 수정 사항이 즉시 반영되는 테스트 환경입니다.
  • 스테이징(Staging) (포트 8080): 안정성이 검증된 코드만 배포되는 상시 가동 환경입니다.
