📖 트레이딩 시스템 가이드

1. 시스템 아키텍처

본 시스템은 대시보드에서 설정한 전략에 따라 독립적인 봇 프로세스가 실시간으로 시장을 감시합니다. 데이터는 한국투자증권(KIS) API와 네이버 금융을 상호 보강하여 수집합니다.

2. 매매 로직 상세

A. 진입 (Entry)

  • 기술적 지표: RSI가 30 이하로 과매도 상태이거나, 볼린저 밴드 하단을 깨고 반등할 때 자동 매수합니다.
  • 수동 가격: 사용자가 지정한 4개 가격 중 하나라도 터치하면 기술 지표와 상관없이 즉시 매수합니다.
  • 모멘텀 모드: 지표를 무시하고 거래량과 주가 돌파를 기반으로 추격 매수합니다.

B. 관리 (Holding)

  • 익절: 평단가 대비 설정된 '목표 수익' 도달 시 전량 매도합니다.
  • 물타기: 평단가 대비 설정된 '하락폭' 도달 시 1:2:4:8 가중치 비중으로 추가 매수하여 평단가를 효과적으로 낮춥니다.
  • 매구 버튼 (⚡ 매수): 클릭 시 전체 예산의 25%를 즉시 시장가로 매수합니다.
⚠️ 주의사항: NXT(야간) 시장은 시장가 주문을 지원하지 않으므로, 시스템이 현재가 기반의 지정가 주문으로 보정하여 체결을 시도합니다.

3. 환경 정책 안내

  • 개발(Dev) (포트 8081): 실시간 수정 사항이 즉시 반영되는 테스트 환경입니다.
  • 스테이징(Staging) (포트 8080): 안정성이 검증된 코드만 배포되는 상시 가동 환경입니다.
